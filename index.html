1. Universal Biomolecular Workflow & Multi-Format Batch File Handler

UniPPI-OWL is a post-prediction biophysical auditing engine: generate 3D complexes from full-length amino acid sequences in AlphaFold3 Server (or ColabFold / Boltz-1 / X-ray PDB), then upload the resulting .cif/.pdb coordinates and companion .json confidence files below as a batch.

Step 1 · AF3 Server Input
Any Predictor or PDB Input
Accepts structures from AlphaFold3 Server (e.g. full-length Arabidopsis VIP1 341 aa), ColabFold/AF2, Boltz-1, Chai-1, ESM3, HADDOCK, or RCSB PDB X-ray/Cryo-EM/NMR.
Step 2 · Batch File Handler
Auto-Pair .CIF/.PDB + .JSON
Upload multiple .cif, .mmcif, .pdb, *_confidences.json / *_full_data_0.json (PAE), and *_summary_confidences.json (ipTM) files together.
Step 3 · Domain & PTM Audit
IDR-Immune PAE & pSer115 Gating
Isolates ordered coiled-coil/globular interfaces from disordered tails via local PAE (LIS) and audits R-S-X-pS-X-P 14-3-3 phosphate clamps.
Step 4 · 3D Structural Relaxation
Global Helix Kink & Δdi,j Shift
Substitutions physically perturb 3D coordinates (e.g. 26° α-helical Proline kink unzipping downstream heptads) and recompute all atom distances.
BATCH STRUCTURE & JSON FILE HANDLER (Drag & Drop or Browse Files/Folders)

Mechanistic Classification & Scientific Scope

From 3D Coordinates & PAE Matrices to Biological Prioritization

UniPPI-OWL categorizes candidate interactions into four mechanistic patterns (Patterns A–D) and defines explicit thermodynamic scope boundaries.

Pattern A

Concordant Rigid / Coiled-Coil or Globular Interactor

UIS ≥ 0.5000 + ipTM ≥ 0.60 + ΔGuni ≤ −6.5 kcal/mol. Global topology, local PAE coherence (LIS), and interfacial solvation thermodynamics all support high-affinity binding across both hydrophobic zippers (VIP1) and electrostatic complexes (Barnase–Barstar).

Pattern B

IDR-Diluted Local Interactor

Strong local LIS (≥ 0.50) & ΔGuni (≤ −7.0 kcal/mol) + Low global ipTM (< 0.60). Rescues true interactions in full-length eukaryotic and plant proteins (e.g., VIP1–14-3-3 GRF6) where long non-interacting disordered tails dilute global ipTM.

Pattern C

Thermodynamically Penalized / Kink-Disrupted

Chains placed in proximity, but offset by intra-helical Proline kinks, steric clashes, or polar desolvation. Exemplified by Group E bZIP homodimers (AtbZIP34) where internal Prolines disrupt the leucine-zipper α-helix.

Pattern D

Below-Threshold Decoy or IDR Hallucination

UIS < 0.5000 with low confidence weight wi,j. Spurious close-range contacts formed by low-confidence disordered loops (pLDDT < 40, PAE > 20 Å) are damped by >99.9%, locking ΔGuni at the +2.10 kcal/mol cratic barrier.

What UniPPI-OWL v1.8 Evaluates:
  • Confidence-weighted 8-channel atomic interactions (salt bridges & PTM phosphate clamps, H-bonds, hydrophobic packing, aromatic π-stacking, disulfides, clashes, helical Proline kinks, and divalent metal-ion coordination).
  • 64-point Golden-Spiral Shrake–Rupley SASA, confidence-weighted buried surface area (wBSA), and Non-Interacting Surface (NIS) properties.
  • Hybrid contact-gated free energy (ΔGuni, Kd) and 20-amino-acid site-directed mutational ΔΔG shifts.
  • Automated sanitization of multi-chain AF3 mmCIF into strict 80-column FoldX/Rosetta PDB and ligand SDF files.
UniPPI-OWL v1.8 Scope Boundaries (Does Not):
  • Replace explicit-solvent molecular dynamics (MD) or wet-lab isothermal titration calorimetry (ITC) / SPR measurements.
  • Use black-box neural network voting to hide disagreements between global ipTM and local interface energetics.
  • Upload or transmit any structural data to external servers (100% of execution occurs locally in browser RAM).
